# Constitutional Schedules Map v0.1
## Modular Constitutional Commonwealth

## Purpose

This map identifies which details should remain in the core Constitution and which should move into schedules, constitutional statutes, system charters, or implementation codes.

The goal is to keep the public Constitution legible while preserving technical precision.

Core rule:

> Keep principles in the Constitution. Put parameters, procedures, formulas, and operational mechanics in schedules.

---

# I. Document Architecture

The constitutional system should eventually be organized into four layers.

| Layer | Purpose | Example |
|---|---|---|
| **Core Constitution** | Foundational rights, systems, powers, limits, doctrines | Democratic Kernel, rights floor, no hidden sovereign |
| **Constitutional Schedules** | Parameters, thresholds, formulas, classifications | electoral thresholds, emergency timelines |
| **System Charters** | Detailed operating rules for each constitutional system | Integrity System Charter, Technology System Charter |
| **Implementation Codes** | Administrative procedures and technical standards | interface usability standards, data schemas |

---

# II. What Belongs in the Core Constitution

The core Constitution should keep:

1. Preamble and governing purpose
2. Democratic Kernel
3. Rights of citizens and persons
4. Public Accountability Right
5. Five Constitutional Systems
6. Federal / state / local principles
7. Party Power Roles
8. Electoral system principles
9. Legislative and executive structure
10. Rights and Justice System
11. Integrity System purpose
12. Stewardship independence and limits
13. Technology sovereignty limits
14. Emergency power limits
15. Fiscal honesty principles
16. Security neutrality
17. Amendment tiers
18. Transition no-gap rules

The core Constitution should not become an operations manual.

# III. Proposed Constitutional Schedules

## Schedule A — Definitions and Tests

Purpose: consolidate technical definitions and legal tests.

Should include:

- Public Authority definition
- Material Public Function Test
- Material Influence Definition
- Hidden Sovereign Test
- Lawful Advocacy Safe Harbor
- Kernel Effectiveness Test
- Material Impairment Standard

Why schedule:
