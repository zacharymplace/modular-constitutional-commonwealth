## Modular Constitutional Commonwealth

## Purpose

This matrix maps the v0.4 Core Constitution to its controlling schedules, related schedules, system charters, and implementation codes.

Core rule:

> The core states principles. The schedules define constitutional mechanics. System charters define institutional operation. Implementation codes define administrative standards.

# IV. Core Constitution Package Hierarchy

Recommended hierarchy for future patching:

1. Core Constitution controls over schedules.
2. Schedules control over system charters.
3. System charters control over implementation codes.
4. More rights-protective interpretation controls where consistent with the Core Constitution.
5. Schedule O controls classification and process for amendments to schedules.
