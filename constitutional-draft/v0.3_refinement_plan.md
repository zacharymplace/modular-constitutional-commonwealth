# Formal Constitution v0.3 Refinement Plan

## Purpose

This plan converts the v0.2 pressure-test findings into a controlled drafting plan for `formal_constitution_v0.3.md`.

v0.3 should not dramatically expand the architecture. It should improve:

- precision;
- definitions;
- default parameters where safe;
- public usability;
- review paths;
- anti-evasion tests;
- implementation clarity.

Core direction:

> v0.2 is architecturally strong. v0.3 should make the draft harder to evade and easier to use.

---

# Drafting Principles

## 1. Add Precision Without Sprawl

v0.3 should add legal tests and defaults only where ambiguity creates real abuse risk.

## 2. Keep the Constitution Publicly Legible

Technical implementation details should move to:

- constitutional statutes;
- appendices;
- parameter schedules;
- system charters;
- implementation codes.

## 3. Preserve the Core Architecture

Do not alter the central structure unless a contradiction is found:

- Democratic Kernel;
- Framework;
- Modules;
- five constitutional systems;
- ranked party power roles;
- stewardship limits;
- public accountability;
- technology constraints;
- fiscal truth machinery;
- capacity-gated transition.

## 4. Avoid Procedural Paralysis

Every new safeguard should answer:

> Does this prevent real abuse without making ordinary governance impossible?

# Workstream 1 — Definitions and Scope

## v0.2 Issues

- “Public authority” is broad and strong but needs a practical test.
- “Hidden sovereign” is powerful but could be abused against lawful advocacy.
- “Materially affects” appears across technology, public authority, and accountability rules.

## v0.3 Tasks

- Add **Material Public Function Test**.
- Add **Hidden Sovereign Test**.
- Add safe harbor for lawful advocacy, journalism, scholarship, protest, and ordinary political persuasion.
- Add examples or refer to a definitions appendix.
- Harmonize “materially affects,” “materially shapes,” and “material influence.”

## Proposed Additions

- `Material Public Function Test`
- `Hidden Sovereign Test`
- `Lawful Advocacy Safe Harbor`
- `Material Influence Definition`

# Workstream 2 — Democratic Kernel and Rights

## v0.2 Issues

- Kernel Effectiveness is strong but needs a materiality threshold.
- Rights limitation standard needs burden of proof.
- “Under Commonwealth authority” needs jurisdictional definition.
- Fast rights rules need continued precision.

## v0.3 Tasks

- Add **Material Impairment Standard** for Kernel review.
- Add **government burden of proof** for rights limitations.
- Define **under Commonwealth authority**.
- Add heightened scrutiny for high-risk rights: voting, detention, speech, surveillance, emergency restrictions, due process.
- Add examples of Kernel impairment versus ordinary reform.

## Proposed Additions

- `Material Impairment Standard`
- `Under Commonwealth Authority Definition`
- `Rights Limitation Burden Rule`
- `Heightened Review for High-Risk Rights`

# Workstream 3 — Public Accountability and Usability

## v0.2 Issues

- Public Accountability Cure Rule needs defect categories and cure timing.

  - bad-faith concealment.

- Add **Non-Digital Access Rule**.
- Require accountable office names, not only agency names.

## Proposed Additions

# What v0.3 Should Not Do

v0.3 should not:

- redesign the entire system;
- add new constitutional systems;
- create more branches;
- fully hard-code all technical parameters;
- turn every recommendation into a constitutional rule;
- bury the public-facing logic under legal complexity;
- create procedural vetoes everywhere;
- overcorrect into paralysis.

---

# v0.3 Success Criteria

v0.3 is successful if it:

- closes obvious evasion paths;
- adds clearer definitions and legal tests;
- preserves democratic legitimacy;
- improves public usability;
- avoids major architectural expansion;
- clarifies review and appeal mechanisms;
- adds safe default parameters where useful;
- leaves technical mechanics to constitutional statutes where appropriate.
